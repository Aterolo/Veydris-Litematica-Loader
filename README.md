# Veydris Litematica Loader

A lightweight launch page for the Eaglercraft 26.2 client.

## Required client file

Place the Litematica-enabled client HTML in this repository as **`client.html`**.

## Launch

Open `index.html` (or enable GitHub Pages for the `main` branch and root folder). Press **PLAY**. The loader fetches `client.html`, creates a Blob URL, and opens the game in a new tab.

The loader page is committed. The game itself is not included until `client.html` is added.
